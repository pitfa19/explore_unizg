Sveučilište u Zagrebu

Pitaj o kolegijima.

Pitaj omiljenog agenta o kolegijima Sveučilišta u Zagrebu običnim jezikom. Odgovori dolaze iz službenog ISVU kataloga i sveučilišnih pravila horizontalne mobilnosti, a ne iz pamćenja modela.

01

Dodaj MCP

https://explore-unizg.vercel.app/api/mcp
  1. Otvori Customize, zatim Connectors.
  2. Add custom connector i zalijepi adresu iz trake.
  3. Autentifikacija: bez prijave. Poslužitelj je javan i ne traži ključ.

Isti konektor vrijedi na webu, u mobilnoj aplikaciji i u Claude Desktopu. Zahtjev ide s Anthropicovih poslužitelja, zato adresa mora biti javni HTTPS.

U terminalu, iz mape projekta:

claude mcp add --transport http unizg-courses https://explore-unizg.vercel.app/api/mcp

Ili u .mcp.json. Polje type mora biti http, inače Claude Code preskoči unos.

{
  "mcpServers": {
    "unizg-courses": {
      "type": "http",
      "url": "https://explore-unizg.vercel.app/api/mcp"
    }
  }
}

U ~/.cursor/mcp.json za sve projekte, ili u .cursor/mcp.json za jedan projekt. Spremi i ponovno otvori Cursor. Poslužitelj je pod Settings → MCP.

{
  "mcpServers": {
    "unizg-courses": {
      "url": "https://explore-unizg.vercel.app/api/mcp"
    }
  }
}
  1. U pregledniku otvori Plugins (chatgpt.com/plugins). Mobilna aplikacija ovo ne zna.
  2. Add custom MCP server. Ime: UNIZG. Adresa je ona iz trake. Autentifikacija: bez prijave.
  3. Potvrdi upozorenje, instaliraj dodatak i uključi ga u novom razgovoru.

Business, Enterprise i Edu imaju puni pristup. Pro čita. Plus, Go i Free u OpenAI-jevoj dokumentaciji nisu zajamčeni: ako stavke nema u izborniku, plan je ne podržava.

U ~/.codex/config.toml:

[mcp_servers.unizg-courses]
url = "https://explore-unizg.vercel.app/api/mcp"

Ili iz terminala. Desktop, CLI i proširenje dijele tu datoteku.

codex mcp add unizg-courses --url https://explore-unizg.vercel.app/api/mcp

Zašto MCP, a ne vještina: podaci su živi, instalacija je jedna poveznica i radi u svakom agentu koji zna MCP.
