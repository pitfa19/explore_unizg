# Explore UNIZG read-only projection

## Intent
Preserve a provenance-pinned, read-only MOZAK projection of the existing Explore UNIZG codebase and its seven owner-authored source notes so future planning can distinguish observed facts, stated direction, and unresolved work.

## Desired outcomes
The projection validates offline, keeps byte-identical content-addressed note objects, exposes source freshness checks, and records a small accepted planning DAG whose goals remain planned or ready rather than claiming unperformed work is complete.

## Boundaries
Authority remains with the repository owner and the original Obsidian notes. This `.mozak` tree is descriptive planning context only, grants no authority to edit the codebase or source vault, and does not convert note claims into verified implementation status. The current scheduler and the proposed university-wide catalog are deliberately different applications: the scheduler is programme-deep and prerequisite-edge focused, while the catalog plan is university-wide and search focused, with catalog output intended to feed programmes into the scheduler.

## Assumptions
The pinned Git revisions and SHA-256 values identify the observed snapshots. Source freshness is a separate explicit check. Note statements about deployment, research, coverage, legal interpretation, and prior evaluations remain attributed to those notes unless independently revalidated.

## Open questions
Which catalog milestone should be implemented next, how catalog and scheduler data exchange should be versioned, and which unresolved source-note follow-ups should be prioritized remain owner decisions.
